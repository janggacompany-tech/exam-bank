# 레벨 진단 시험 (문제은행)

서버 없이 동작하는 객관식 시험 페이지입니다. 응시자가 이름·전화번호·이메일을 입력하면
5개 레벨의 문제은행에서 레벨당 5문항(설정 가능)을 무작위로 뽑아 시험지를 만들고,
타이머가 돌아가며, 제출하면 자동으로 채점됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 시험 페이지 전체 (응시 화면 + 관리자 화면) |
| `questions.js` | 문제은행 데이터. 관리자 화면에서 내려받아 교체 |
| `apps-script.gs` | 응시 결과를 구글 시트에 모으는 스크립트 (선택) |

## 바로 써 보기

`index.html`을 더블클릭해 브라우저로 열면 바로 응시할 수 있습니다.
지금은 동작 확인용 예시 문항(레벨당 8개)이 들어 있습니다.

관리자 화면은 주소 끝에 `#admin`을 붙여 엽니다. 초기 비밀번호는 `admin1234` 입니다.

## 현재 들어 있는 문항

장가컴퍼니 외식업경영 LEVEL 1~5 문제지(Word)에서 변환한 500문항(레벨당 100문항)이 `questions.js`에 들어 있습니다.
LEVEL 1~4는 5지선다 객관식, LEVEL 5는 숫자를 직접 적는 **계산형(주관식)** 입니다.
시험은 5개 레벨 × 5문항 = 25문항, 제한 시간 30분으로 출제됩니다.

### 계산형 문항 채점 방식

- LEVEL 5는 20개 CASE × 5문항 구조라서, 시험마다 CASE 하나를 통째로 뽑아 5문항을 순서대로 냅니다.
- 응시자는 숫자만 입력하면 됩니다. 쉼표·단위(원, 팀, %)는 있어도 없어도 되고 "1,600만원"처럼 써도 됩니다.
- 정답과의 차이가 허용 오차(기본 0.2%) 안이면 정답입니다. 비율 답은 ±0.01%p, 정수 답은 ±0.5까지 기본 허용됩니다.
- "A / B / C"처럼 답이 여러 개인 문항은 칸이 여러 개 나오고, 모두 맞아야 정답입니다. "손익선 안/밖"은 버튼으로 고릅니다.
- 허용 오차는 관리자 → 설정에서 바꿀 수 있습니다.

## 이해도 분석 · 복습 추천 (교안 연동)

`guide.js`에 교안(장가컴퍼니 외식업 경영 기본 교안, PART 1~12)이 들어 있습니다. 제출 후 결과 화면에:

- **이해도 분석**: 이번 시험에 나온 문항을 분류별로 나눠 정답 수와 상태(탄탄/보통/부족)를 보여 줍니다.
- **복습 추천**: 틀린 문항의 분류에 연결된 교안 PART를 골라, 핵심 정리(소제목·공식·인용) → 교안 전체 내용(펼치기) → 틀린 문항의 내 답·정답·풀이 순으로 보여 줍니다.
- 관리자 응시 결과와 구글 시트에도 "복습 파트", "분류별" 값이 함께 기록됩니다.

문항 분류와 PART의 연결은 `guide.js`의 `topicMap`(분류 이름 → PART 번호)에 있고, 없는 분류는 `keywordMap` 키워드 규칙으로 찾습니다.
교안을 바꾸려면 관리자 → **교안** 탭에 Word(.docx)를 올리고 `guide.js`를 내려받아 교체합니다. (Word의 제목 1 = PART, 제목 2·3 = 소제목)

## 문항 등록 · 교체

### 방법 1: Word 문제지 그대로 올리기

관리자 → **문항 관리** 에 `.docx` 파일을 끌어다 놓으면 바로 읽습니다. 문서가 아래 형식이면 됩니다.

- 문항: `1. 문제 내용` 으로 시작하고, 보기는 `①`~`⑤` 로 시작하는 줄
- 단원 제목: `01–020  단원명` 형태의 줄 (있으면 "분류"로 저장)
- 문서 끝에 **정답표**: 문항 번호와 `①`~`⑤` 기호가 짝을 이루는 표
- 문서 안의 `LEVEL 1`~`LEVEL 5` 표기로 레벨을 자동 인식합니다 (없으면 화면에서 직접 선택)

읽은 뒤 **같은 레벨만 교체** 를 누르면 그 레벨의 기존 문항만 새 문항으로 바뀝니다.
(새 레벨 문서를 추가할 때는 **기존 문항에 추가** 를 누르면 됩니다.)

### 방법 2: 엑셀 / CSV

1. "양식 내려받기"로 엑셀 양식을 받아 아래 열 순서대로 채웁니다. 한 행이 한 문항입니다.

   | 레벨 | 문제 | 보기1 | 보기2 | 보기3 | 보기4 | 보기5 | 정답(번호) | 해설 | 분류 |
   |---|---|---|---|---|---|---|---|---|---|
   | 1 | 매출을 가장 기본적으로 분해한 식은? | 객수 × 객단가 | 신규 × 재방문 | 광고비 × 전환율 | 노출 × 리뷰 | LTV × CAC | 1 | | 사업·매출·비용의 기본 |

   - 레벨은 1~5, 정답은 보기 번호(1~5), 해설·분류는 비워도 됩니다.
   - 보기가 4개뿐인 문항은 보기5를 비워 두면 됩니다.
2. 파일을 관리자 화면에 끌어다 놓고 교체 또는 추가를 누릅니다.

### 마지막 단계 (공통)

**questions.js 내려받기**를 눌러 받은 파일로 폴더의 `questions.js`를 덮어씁니다.
가져온 문항은 우선 그 브라우저에만 임시 저장(초안)되므로, 이 단계를 해야 응시자에게 적용됩니다.
(웹에 올린 경우에는 교체한 questions.js를 다시 업로드합니다.)

## 시험 설정

관리자 → **설정**에서 바꿀 수 있습니다.

- 레벨당 출제 문항 수 (기본 5 → 총 25문항)
- 제한 시간 (기본 25분, 0이면 무제한)
- 합격 기준 정답률 (기본 60%)
- 보기 순서 섞기, 제출 후 정답 공개 여부
- 관리자 비밀번호
- 결과 전송 주소 (구글 시트)

설정도 브라우저에 저장되므로, 배포 시 모든 응시자에게 적용하려면
`index.html` 안의 `DEFAULT_CONFIG` 값을 같은 내용으로 바꿔 두세요. (설정 탭의 "설정 JSON 복사" 참고)

## 응시 결과 모으기 (구글 시트)

결과는 기본적으로 응시자가 사용한 브라우저에만 저장됩니다.
여러 사람의 결과를 한곳에 모으려면 `apps-script.gs` 상단의 설명대로 구글 시트에 스크립트를 배포하고,
나온 웹 앱 URL을 설정의 "결과 전송 주소"와 `DEFAULT_CONFIG.webhookUrl`에 넣으세요.
제출 즉시 시트에 한 줄씩 쌓입니다.

## 배포 (응시자에게 링크 보내기)

이 폴더를 그대로 정적 호스팅에 올리면 됩니다.

- Netlify Drop(https://app.netlify.com/drop)에 폴더를 끌어다 놓기 → 링크 발급
- GitHub Pages, Cloudflare Pages, 회사 홈페이지의 하위 폴더 등도 동일

## 동작 방식

- 시작 시 레벨 1→4 순서로 각 레벨에서 무작위 추출, 보기 순서도 무작위(설정 가능)
- 제한 시간은 시작 시각 기준으로 계산되어 새로고침해도 이어집니다. 시간이 끝나면 자동 제출
- 답안은 문항마다 즉시 저장되어 새로고침해도 유지됩니다 (같은 탭에서만)
- 숫자 키 1~4로 선택, ←/→ 로 이동
- 채점: 총점, 정답률, 레벨별 정답 수, 합격 여부, 소요 시간

## 참고

- 관리자 비밀번호는 페이지 소스에서 볼 수 있는 간단한 잠금입니다. 결과 원본은 구글 시트에 두세요.
- 엑셀(.xlsx) 읽기·쓰기는 인터넷이 연결되어 있어야 합니다(라이브러리를 CDN에서 불러옴). 오프라인이면 CSV를 쓰세요.
